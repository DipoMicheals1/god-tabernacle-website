## 📖 About The Ministry
God's Tabernacle is a faith-based ministry dedicated to spreading the gospel through teaching, worship, and community support. **The Messengers** are the voice and hands of this ministry, reaching souls worldwide through digital platforms.

## ✨ Features

### 📚 Media Library
- **Downloadable Books** - Spiritual teachings and biblical studies (PDF format)
- **Audio Sermons** - Sunday and Wednesday services (MP3 format)
- **Video Teachings** - YouTube integrated sermons and worship sessions
- **Worship Music** - Original and curated gospel music

### 📞 Support System
- **Video Calls** - Face-to-face support using Jitsi Meet (free, no account required)
- **Audio Calls** - Voice-only support option
- **Missed Call Logging** - Records unanswered support requests (local storage)
- **WhatsApp Business** - Direct chat support
- **Telephone Support** - Traditional phone line

### 💬 Community Features
- **Comment Section** - GitHub Discussions powered comments via Giscus
- **Contact Form** - Email submissions via Formspree (50 free submissions/month)
- **Social Media Integration** - Facebook presence (@MESSENGERs)

### 💰 Donations
- **PayPal Donate** - One-time and recurring donations
- **Buy Me a Coffee** - Alternative support platform
- **Bank Transfer** - Direct church account details

### 📱 Mobile App Integration
- **API Endpoint** - JSON feed for your existing mobile app
- **Book Downloads** - Direct download URLs for in-app integration
- **Cross-Platform** - Works with Android and iOS apps
